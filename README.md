# Erörterungstrainer

Ein Trainer fuer lineare und dialektische Eroerterungen. Der Modus ist per Button waehlbar. Jede Maske fuehrt durch Einleitung, Argumente und Schluss.

## Start

Einfach die `index.html` im Browser oeffnen.

## Features

- Zwei Modi: linear und dialektisch
- Pro Abschnitt eigene Eingabemasken
- Argumente hinzu- oder entfernen (automatische Nummerierung)
- Prüfworkflow: fehlerhafte/unvollständige Argumente werden mit konkreten Hinweisen abgewiesen
- Stimmige Argumente werden sichtbar in die Disposition übernommen; Änderungen lösen eine neue Prüfung aus
- Aufbau nach der Unterrichtsvorlage: steigende lineare Gewichtung sowie Contra–Wendepunkt–Pro
- Übungsspiel mit automatisch zugelosten linearen und dialektischen Aufsatzthemen
- Drei Spielarten: linear, dialektisch und gemischt
- Flexible Aufgabenformen: vollständiges Thema, Thema mit einem fest eingesetzten Argument, strenge Rekonstruktion aus einem einzelnen Argument und Zufallsmodus
- Kuratierte Rekonstruktionsaufgaben mit eindeutiger Argumentposition, verpflichtenden Schlüsselbegriffen und gesperrter strenger Prüfung
- 72 abwechslungsreiche Themen aus zahlreichen Lebens- und Wissensbereichen
- Erwartete Tendenz bei dialektischen Themen sowie Live-Fortschritt über alle Textbausteine
- Lokaler Textgenerator: Setzt eine vollständig geprüfte Disposition ohne API oder Datenübertragung zu einem überarbeitbaren Aufsatzentwurf zusammen
- Export als TXT oder DOCX
- Druck/Export als PDF ueber den Browser
